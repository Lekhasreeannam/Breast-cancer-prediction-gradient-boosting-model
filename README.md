# 🩺 Breast Cancer Prediction System

A Machine Learning-based web application that predicts whether a breast tumor is **Benign** or **Malignant** using a trained **Gradient Boosting Classifier**.

The project includes data analysis, machine learning model development, preprocessing, model serialization, and deployment through an interactive **Streamlit** web application.

## 📌 Project Overview

Breast cancer is one of the most common health conditions affecting women worldwide. Early identification and classification of tumors can support timely medical evaluation.

This project uses machine learning to classify breast tumors into:

- 🟢 **Benign** — Non-cancerous tumor
- 🔴 **Malignant** — Cancerous tumor

The trained machine learning model is integrated into a Streamlit application where users can enter feature values and receive a prediction.

## 🤖 Machine Learning Model

The deployed application uses a:

**Gradient Boosting Classifier**

The trained components are stored using Python Pickle:

- `model.pkl` — Trained machine learning model
- `scaler.pkl` — Fitted feature scaler
- `features.pkl` — Feature names and their required order

The application applies the same feature order and scaling used during model training before generating a prediction.

## 📊 Dataset

The project uses the **Breast Cancer Wisconsin Dataset**.

The dataset contains numerical characteristics associated with breast tumor samples that are used to distinguish between benign and malignant tumors.

## 💻 Streamlit Application

The project includes an interactive Streamlit interface.

The application:

1. Loads the trained model, scaler, and feature names.
2. Dynamically creates input fields for the required features.
3. Collects the user's input values.
4. Maintains the same feature order used during training.
5. Scales the input using the saved scaler.
6. Sends the processed input to the trained model.
7. Displays the final prediction.

### Prediction Output

The application displays:

**🔴 Malignant Tumor**

or

**🟢 Benign Tumor**

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone <your-repository-url>
cd Breast-Cancer-Prediction
```

### 2. Install Required Libraries

```bash
pip install pandas scikit-learn streamlit
```

### 3. Make Sure These Files Are Present

```text
model.pkl
scaler.pkl
features.pkl
app.py
```

The saved model files should be in the same directory as `app.py`.

### 4. Run the Streamlit Application

```bash
streamlit run app.py
```

The application will open in your browser.
